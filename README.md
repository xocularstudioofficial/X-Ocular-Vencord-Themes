# 🎨 X-Ocular Aura Glass — Full UI Theme Pack (Vencord)

Official **X-Ocular Studio** full-overhaul theme pack for **Vencord**. Built around the signature **Aura Glass** visual identity — featuring detached floating frosted-glass panels, subtle ambient glows, decluttered navigation, and unified **Exo 2 SemiBold** typography across the entire Discord client.

---

## 📦 Download & Updates (Releases Only)

> **Important:** Theme files (`.theme.css`) are **not** stored in the main repository tree. All theme builds, patches, and new color variants are published exclusively under **[Releases](../../releases)** to ensure clean version tracking and easy updates.

1. Go to the **[Latest Release](../../releases/latest)** page.
2. Download the `.theme.css` preset you want from the **Assets** section.
3. Whenever a new Discord update drops or UI tweaks are released, grab the latest build from **Releases** and replace your old file.

## ✨ Key Features

* **Floating Aura Glass Architecture:** Separated sidebar, server rail, chat container, user dock, and member list with rounded corners, hairline borders, and ambient glow.
* **Exo 2 SemiBold Typography:** Clean, modern geometric font enforced across headers, channels, usernames, and UI controls.
* **Decluttered Interface:** Removes unnecessary chat bar clutter (Gift/Sticker bloat) for a sharper, distraction-free layout.
* **Multi-Preset Ready:** Built on modular root CSS variables for effortless customization.

---

## 🛠️ Installation Guide

1. Download your preferred `.theme.css` file from **[Releases](../../releases/latest)**.
2. Open Discord and go to **User Settings → Vencord → Themes**.
3. Click **Open Themes Folder** and move the downloaded `.theme.css` file into the folder.
4. Back in Discord, click **Load missing Themes** and toggle the theme **ON**.
